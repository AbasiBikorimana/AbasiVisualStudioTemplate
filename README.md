Simple Visual Studio C++ project template for ease of use.

Feel Free to edit, Have fun!


## Build Outputs

'Common.props' contains shared properties across the projects feel free to edit.

Build outputs are organized under the solution directory:

bin/
├── x64/
│   └── Debug/
│       ├── Default.exe
│       └── SecondDefault.exe
│
└── intermediates/
    ├── Default/
    │   └── x64/
    │       └── Debug/
    │
    └── SecondDefault/
        └── x64/
            └── Debug/


  Output structure may change depending on the selected platform and build configuration
